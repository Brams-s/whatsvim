01

Plain-language summary

WhatsVim is a single-purpose browser extension. Its bundled content scripts run locally only on https://web.whatsapp.com/* to provide keyboard navigation and editing-mode assistance.

✓

It does handle command input transiently and may keep limited visible-interface navigation state in page memory between commands.

×

It does not send that information to the developer or third parties, save it in extension storage or files, share or sell it, or use it for advertising, profiling, or unrelated purposes.

02

What WhatsVim can access

To respond to commands, WhatsVim can inspect and interact with the visible WhatsApp Web interface. This can include chat labels, message rows, media controls, reply or reaction controls, editing controls, the Read more control, and the message composer. Keyboard command input is handled only for the current action. Limited navigation state—selected DOM elements, a message identity or key, and return focus or scroll state—may remain in page or content-script memory between commands until replaced or cleared, or until the page unloads or the extension context is destroyed. This state supports navigation targets and position; it is not a separately stored archive of raw message content.

That access is limited by the extension manifest to WhatsApp Web. WhatsVim cannot run on other sites under its current configuration. It declares no API permissions or host permissions, and has no background worker.

Data categories

Command input is handled transiently for the current action. Limited navigation state may remain in page or content-script memory between commands until replaced or cleared, or until the page unloads or the extension context is destroyed. Neither is sent to the developer or third parties or written to extension storage or files.

Keyboard command input
Keys used for navigation, selection, mode changes, and visible interface actions, handled only for the current action.
Interface and navigation state
Visible page elements needed to identify a target, plus limited state such as selected DOM elements, a message identity or key, and return focus or scroll state.
Usage and diagnostics
Not recorded. There are no analytics, telemetry, tracking pixels, fingerprints, or crash-reporting services.
Account and authentication data
Not requested or stored by WhatsVim. Sign-in and account traffic belong to WhatsApp Web, not this extension.

04

Retention and sharing

Keyboard command input is handled transiently for the current action. Limited navigation state—selected DOM elements, a message identity or key, and return focus or scroll state—may remain in page or content-script memory between commands until replaced or cleared, or until the page unloads or the extension context is destroyed. None of this is written to extension storage or files. WhatsVim does not use local storage, synced storage, a database, or a remote service to persist personal data.

WhatsVim does not share or sell the information it handles, show advertising, build user profiles, or provide that information to data brokers or other third parties. Because it creates no persistent user-data store, it has no stored personal data to export or delete.

05

Network boundary

WhatsVim makes no extension-initiated network requests. It has no analytics endpoint, telemetry service, remote configuration, or remotely hosted runtime code. Its content scripts and styles are bundled with the extension.

Important boundary

WhatsApp Web makes its own network requests to operate messaging and account features. That traffic is controlled by WhatsApp and is outside WhatsVim’s behavior and this policy.

06

Limited Use statement

WhatsVim does not use Google APIs or receive Google user data. The information it processes on WhatsApp Web is used only to provide the user-facing keyboard navigation and mode behavior described in this policy. It is not used for advertising, profiling, credit, lending, or any purpose unrelated to that single function.

07

Policy changes

This policy reflects WhatsVim’s current implementation. If a future version adds data handling, storage, telemetry, network access, or access to another site, this page will be updated to explain the change before that version is released.

No browser extension can promise absolute security. WhatsVim reduces exposure by minimizing access, keeping execution local, and not maintaining a persistent user-data store.

08

Support and source

Need help, found a bug, or have a privacy question? Open an issue in the public repository. Please do not include private messages, contact details, screenshots of personal chats, or other sensitive information in a public issue.
