# Store assets

This directory is source-controlled for reviewed Chrome Web Store listing
assets. It intentionally contains no generated or illustrative placeholder
imagery.

Before a listing upload, add the required 128×128 icon and at least one
truthful screenshot. Add promotional imagery only if it satisfies the current
dashboard specification. Each asset must represent the shipped extension and
must have an entry in [ASSET-METADATA.md](ASSET-METADATA.md) with its filename,
type/dimensions, capture source, extension version, capture date, redaction
status, reviewer, and update date. Do not use stock, mock, or generated imagery
that could misrepresent the extension.
